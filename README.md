# Student Scores Cleaning & Analysis

This project demonstrates a complete **data cleaning and analysis workflow** using Python and Pandas.

## 📊 Steps:
1. Created a small dirty dataset (`students_dirty.csv`).
2. Cleaned data by:
   - Removing extra spaces and unifying text case.
   - Replacing inconsistent subject names (`maths` → `math`).
   - Handling missing values using mean imputation.
3. Compared average scores before and after cleaning.
4. Visualized results with Matplotlib.

## 🧠 Skills Practiced
- Data Cleaning  
- Pandas GroupBy  
- Handling Missing Data  
- Data Visualization  

## ⚙️ How to Run
1. Open `data_cleaning.ipynb` in Jupyter Notebook.  
2. Run each cell step by step.
